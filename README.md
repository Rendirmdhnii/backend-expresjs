# Tugas #1 Backend - Express.js

Repositori ini berisi bagian Backend untuk Tugas #1 Module PWEB Dev. Proyek ini dibangun dari nol menggunakan **Express.js** dan TypeScript.

## Fitur & Teknologi
- Framework: Express.js
- Bahasa: TypeScript
- Engine: `tsx` dan `ts-node` untuk eksekusi langsung.

## Cara Menjalankan
1. Pastikan Anda sudah menginstal Node.js versi LTS.
2. Buka terminal dan instal dependensi:
   ```bash
   npm install
   ```
3. Jalankan server:
   ```bash
   npm run dev
   ```
4. Buka browser atau Postman dan akses [http://localhost:5000](http://localhost:5000). Jika berhasil, akan muncul respons teks konfirmasi.
